# Radiant Realms

Create a high-converting premium landing page for selling an AI Prompt Library focused on skin care, gut health, nutrition, and fitness.

The goal of this page is:
- Capture leads (email + WhatsApp)
- Sell low-ticket product (₹99–₹299)
- Upsell full prompt library
- Convert users into subscription (₹499/month)

Target audience:
- Women with skin, gut, weight concerns
- Health coaches and consultants

Style:
- Premium, minimal, clean, modern
- Soft neutral colors (beige, white, light gold, pastel green)
- Apple-level spacing and typography
- Mobile-first design

Structure the page for high conversion and clarity.
